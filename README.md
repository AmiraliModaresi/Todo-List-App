# ✨ Todo List App

Yes, I know... another Todo List. 🙄

Because apparently, no developer's portfolio is complete without one. But hey, I thought I'd give this overused beginner project a little personality. So here's my take on it!

A modern, responsive, and customizable Todo List application built with **HTML, CSS, and JavaScript**.

Stay organized, manage your daily tasks, track your progress, and personalize your experience with multiple themes and settings.

## 🚀 Features

### 📝 Task Management
- **Add Tasks:** Easily create and add new tasks to your list.
- **Edit Tasks:** Update your existing tasks whenever you need.
- **Mark as Completed:** Check off completed tasks and keep track of your progress.
- **Delete Tasks:** Remove individual tasks with ease.
- **Delete All Tasks:** Clear your entire task list at once, with a confirmation modal to prevent accidental deletion.
- **Custom Context Menu:** A custom right-click menu built with JavaScript, replacing the browser's default context menu with application-specific actions and shortcuts.

### 📊 Progress Tracking
- **Dynamic Progress Bar:** Automatically calculates and displays the percentage of completed tasks relative to the total number of tasks.
- Get a clear visual overview of your productivity.

### ⚙️ Customization & Settings
- **4 Different Themes:** Choose from four available themes to personalize the app's appearance.
- **RTL Support:** Switch the layout to Right-to-Left (RTL) mode for a better Persian and Arabic reading experience.
- **Custom Fonts:** Toggle between standard fonts and a collection of stylish custom fonts:
  - Persian: `mahboubeh_mehravar`
  - English: `sf-cartoonist-hand`

### 🌍 Additional Features
- **Bilingual Support:** Supports both Persian and English.
- **Fully Responsive:** Optimized for desktop, tablet, and mobile devices.
- **Local Storage:** Automatically saves your tasks and preferences using the browser's Local Storage. Your data stays available even after closing or refreshing the page.
- **Smooth Animations:** Subtle fade animations for menus, modals, and other UI elements.
- **Modern UI:** A clean and visually appealing interface designed for a smooth user experience.
- **Animated Loading Screen:** Displays a smooth looping loading animation while the application initializes, revealing the main interface once everything is fully loaded.

## 🛠️ Built With

- **HTML5** – Application structure
- **CSS3** – Styling, responsive layouts, themes, and animations
- **JavaScript (Vanilla JS)** – Application logic and interactivity

## 📱 Responsive Design

The application is designed to work smoothly across different screen sizes and devices.

## 💾 Data Persistence

All tasks and application settings are stored locally in your browser using the **Local Storage API**.

This means:
- Your tasks remain saved after refreshing the page.
- Your selected theme and preferences are preserved.
- Your data is available when you revisit the application in the same browser.

> **Note:** Data is stored locally in your browser and is not synchronized across different devices or browsers.
